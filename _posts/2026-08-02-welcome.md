Welcome to my site!

This blog is written and published directly here — I just drop a Markdown
file into `_posts/`, push, and GitHub Pages rebuilds it automatically. No
dashboard needed.

## How to publish here

1. Create a file `_posts/YYYY-MM-DD-your-title.md`
2. Add front matter with `title`, `date`, and optional `categories`/`tags`
3. Write the body in Markdown
4. Push to `main` — done
